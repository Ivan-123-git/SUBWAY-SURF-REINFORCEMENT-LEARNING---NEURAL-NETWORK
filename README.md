# Subway Surfers Reinforcement Learning Agent 🚇🤖

A lightweight reinforcement learning project that trains a PyTorch neural network from scratch to play a custom, terminal-based clone of **Subway Surfers**.

This project explores how an AI agent can learn optimal survival strategies and movement policies through trial, error, and reinforcement learning, all rendered right inside your command line.

---

## 🚀 Key Features

* **Custom RL Environment:** A bespoke environment designed specifically to simulate game mechanics, obstacles, and rewards similar to Subway Surfers.
* **PyTorch Neural Network:** A Feed-Forward Neural Network trained via backpropagation to map game states to actions.
* **Dual-Mode Execution:**
* **Headless Mode:** Optimized for speed, running hundreds of iterations silently to train the neural network from scratch efficiently.
* **Live Terminal Mode:** Allows you to watch the trained agent play the game in real-time right inside your terminal.
